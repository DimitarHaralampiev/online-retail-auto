# Visual assets

The storefront uses the built-in `imagegen` tool. These are generated editorial and illustrative demo assets, not photographs of supplier inventory. The SVG brand mark and interface icons are code-native assets. AUTO/SHOP is a provisional identity.

## Hero

Saved path: `public/images/garage-hero.png`

Prompt:

```text
Use case: ads-marketing. Asset type: wide hero photograph for a premium Bulgarian automotive parts and accessories storefront. Primary request: create a beautiful, distinctive cinematic automotive editorial image. Scene: architectural concrete garage at dusk, a single unbranded graphite metallic sports touring car seen from a low front three-quarter angle, parked facing left, sleek clean realistic bodywork and headlights. Composition: very wide landscape 16:9; car occupies the right two thirds, left third is dark negative space for HTML headline overlay, generous space above. Lighting: subtle warm orange strip lights reflecting on concrete and body, cool graphite shadows, refined studio lighting, authentic materials, dramatic but tasteful. Color palette: charcoal, warm gray, tiny burnt orange accents. No people, no text, no logos, no watermarks, no visible license numbers. Photorealistic high-end automotive campaign, not a website mockup. Save a local file if supported.
```

## Typography and display

Manrope Variable is used for interface text; Roboto Condensed Variable is used for display headings. Both are bundled locally via Fontsource, including Cyrillic support. Next.js Image provides responsive image delivery. Generated source files remain in the repository; production should cache the optimized variants.
