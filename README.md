# Online Retail Auto

Начална основа на онлайн магазин за автоаксесоари и части за България със собствен склад.

## Локално стартиране

Изисква Node.js 20.9+ и npm.

```bash
npm ci
npm run dev
```

Отвори http://localhost:3000. Началната страница е на български, с временно име и примерни направления на каталога.

## Проверки и production build

```bash
npm run typecheck
npm run build
npm start
```

`typecheck` проверява TypeScript, `build` подготвя production версия, а `start` я стартира след успешен build. Все още няма автоматизирани тестове.

## Структура

- `src/app/page.tsx`: начална страница.
- `src/app/layout.tsx`: общ layout и metadata.
- `src/app/globals.css`: стилове и адаптация за мобилни устройства.
- `AGENTS.md`: указания за принос към проекта.

## Следващи стъпки

1. Избор на име и визуална идентичност.
2. PostgreSQL/Supabase: продукти, доставчици, доставки и складови движения.
3. Защитена администрация за каталог и наличности.
4. Качване на фактури, AI разчитане и потвърждение преди заприхождаване.
5. Клиентски каталог, количка, резервация на наличности и поръчки.
6. Доставка, плащания, хостинг и резервни копия.
7. Сравняване на конкурентни цени и предложения за ценообразуване.

Текущата версия е само начална страница: няма база, вход, приемане на поръчки или AI интеграция. За локалното стартиране не са необходими ключове или платени услуги. Фактурите и личните данни трябва да се съхраняват защитено при добавяне на съответните модули.
